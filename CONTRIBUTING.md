# Contributing

Use English for code, comments, commits, issues, pull requests, documentation, and interface copy.

Run `npm ci`, `npm test`, and `npm run check` before submitting a change. Keep the product small: a personal library, impressions, chosen context, and thoughtful recommendations.

Do not add analytics, background data collection, API-key billing, or automatic context uploads. Keep authentication tokens in the desktop main process. Treat imported documents and catalog data as untrusted input. Use synthetic fixtures, never personal conversations or real credentials.

For UI changes, check keyboard navigation, readable contrast, and the smallest supported window. Prefer ordinary text fonts for body copy; use pixel lettering sparingly.

Explain the user-visible behavior and how you checked it in your pull request. Report security issues privately as described in `SECURITY.md`.
