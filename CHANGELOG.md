# Changelog

## 0.1.0 — Public preview

- First independent local desktop release, with a new English-only interface and a dark, nostalgic reading-room design.
- Local cover shelf for books, manga, games, videos, films, podcasts, and articles.
- Live public-catalog search, optional cover uploads, written and recorded impressions.
- Reviewed import of selected ChatGPT conversations and text / Markdown context.
- ChatGPT plan connection through the documented open-source OAuth flow, without a separate API key.
- On-demand catalog discovery and recommendations grounded in selected context and written impressions.
- Separate shelves per registration, encrypted OAuth credentials, library export and restore.

This preview is unsigned. ChatGPT eligibility varies, voice transcription and cloud sync are not included, and the app never obtains ChatGPT conversation history through sign-in.
